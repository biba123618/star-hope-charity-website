# star-hope-charity-website
📌 Description
Star Hope is a responsive charity website designed to promote humanitarian causes, accept donations, and spread awareness. It features a clean and user-friendly interface that allows users to learn about the organization's mission, events, and ways to contribute.

🚀 Featured Sections
.Home Page with mission statement and CTA (Call To Action)

.About Us page showcasing the charity's purpose and values

.Donate page with simple form interface

.Contact Form to get in touch with the organization

.Events Section highlighting upcoming charity drives

💻 Technologies Used
.HTML5

.CSS3

.JavaScript

.Bootstrap (for responsiveness and layout)
